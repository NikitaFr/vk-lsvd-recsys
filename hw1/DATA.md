## Данные и задача

Задача — формирование персональных top-10 рекомендаций видео. Сравниваются ItemKNN, iALS, EASE, Factorization Machine (FM) с метапризнаками и iALS с непрерывным самостоятельно разработанным целевым сигналом.

Итоговая выборка после подготовки содержит **3 000 пользователей**, **2 000 видео** и **1 483 828 взаимодействий**. Используется временное разделение: недели **00–24** — train, **25** — validation, **26** — test.

Основная метрика — **NDCG@10**, дополнительные — **Recall@10** и **MAP@10**. Правила релевантности, формирование подвыборки, очистка, EDA, пространство гиперпараметров и результаты представлены в [`experiments.ipynb`](experiments.ipynb).

## Запуск и воспроизведение

Требуется Python 3.12+. Команды ниже выполняются **из директории `hw1/`**:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m ipykernel install --user --name vk-lsvd --display-name "Python (VK-LSVD)"
python -m jupyterlab experiments.ipynb
```

В Jupyter выберите ядро `Python (VK-LSVD)`. По умолчанию в ноутбуке установлено `REPRODUCE=False`: используются сохранённые результаты без повторного обучения. Для повторного обучения и оценки установите `REPRODUCE=True` и выполните ноутбук с начала.

При повторном обучении данные загружаются автоматически. Для отдельной подготовки данных из `hw1/` выполните:

```bash
python -m models.prepare_data
```

Команды для отдельных исследований EDA и настройки моделей приведены в разделе 8 ноутбука. Реализации находятся в `models/`, вспомогательные функции — в `models/utils/`, экспериментальные сценарии — в `models/experiments/`.

Исходные данные и промежуточные результаты создаются локально и исключены из Git; загружать их в репозиторий не требуется.
